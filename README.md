اسم المشروع:
USB Media Explorer

الفكرة:
تطبيق Android احترافي لإدارة وتصفح الملفات، مصمم بشكل أساسي لتصفح الأفلام والفيديوهات والصور الموجودة على وحدات التخزين الخارجية USB OTG والفلاشات وبطاقات SD.

الهدف الأساسي:
عند توصيل فلاشة USB بالهاتف، يستطيع المستخدم فتحها وتصفح المجلدات والملفات بشكل طبيعي مثل Windows Explorer، لكن عند وجود فيديوهات أو صور يجب أن يعرض التطبيق معاينات حقيقية للمحتوى بدل أيقونات الملفات التقليدية.

أهم شرط في التطبيق:
يجب إنشاء Thumbnail حقيقي للفيديو من داخل ملف الفيديو نفسه، وليس مجرد أيقونة فيديو، وليس بوستر يتم تحميله من الإنترنت.

مثال:

USB
└── Movies
    ├── Ballerina (2025).mkv
    ├── Zootopia (2016).mp4
    ├── The Odyssey (2026).mkv
    └── Big Hero 6.mp4

يجب أن يظهر المجلد بهذا الشكل:

┌──────────────────┐   ┌──────────────────┐
│                  │   │                  │
│   FRAME من       │   │   FRAME من       │
│   Ballerina      │   │   Zootopia       │
│                  │   │                  │
├──────────────────┤   ├──────────────────┤
│ Ballerina (2025) │   │ Zootopia (2016)  │
│ 2.4 GB • 1080p   │   │ 1.8 GB • 1080p   │
└──────────────────┘   └──────────────────┘

ولا تظهر أيقونة الفيديو إلا إذا تعذر إنشاء المعاينة فعليًا.

==================================================
1. دعم USB / OTG
==================================================

يجب أن يدعم التطبيق:

- USB Flash Drives.
- USB OTG.
- USB SSD/HDD عند دعمهما من الجهاز.
- SD Card.
- التخزين الداخلي.
- أنظمة FAT32.
- exFAT.
- التعامل مع وحدات التخزين الخارجية من خلال Android Storage Access Framework عند الحاجة.

عند توصيل USB:

- اكتشاف وحدة التخزين تلقائيًا.
- إظهار اسم الوحدة.
- إظهار المساحة المستخدمة والفارغة.
- طلب صلاحية الوصول مرة واحدة فقط.
- الاحتفاظ بإذن الوصول للوحدة طالما يسمح Android بذلك.
- التعامل الصحيح مع فصل الفلاشة.
- تحديث المحتوى عند إعادة توصيلها.

يجب ألا يشترط التطبيق نسخ الفيديوهات إلى ذاكرة الهاتف لإنشاء المعاينات.

==================================================
2. شاشة تصفح الملفات
==================================================

الواجهة الأساسية يجب أن تشبه Windows Explorer من حيث الفكرة، لكن بتصميم Android حديث.

في أعلى الشاشة:

- زر الرجوع.
- اسم المجلد الحالي.
- مسار المجلد Breadcrumb.
- زر البحث.
- زر تغيير طريقة العرض.
- زر الفرز.
- زر القائمة.

طرق العرض:

1. قائمة.
2. Grid صغير.
3. Grid متوسط.
4. Grid كبير.
5. Grid ضخم للوسائط.

الوضع الافتراضي لمجلدات الأفلام:
Grid كبير أو ضخم.

==================================================
3. معاينات الفيديو
==================================================

هذه أهم وظيفة في التطبيق.

لكل ملف فيديو:

- قراءة الفيديو من USB مباشرة.
- استخراج Frame مناسب من الفيديو.
- تحويله إلى Thumbnail.
- حفظ Thumbnail في Cache منفصل.
- إعادة استخدام Thumbnail لاحقًا بدل استخراج الفيديو مرة أخرى.
- عدم تعديل ملف الفيديو الأصلي.
- عدم إنشاء ملفات مخفية بجانب الفيلم على الفلاشة إلا إذا اختار المستخدم ذلك صراحة.

يجب أن تكون المعاينة:

- واضحة.
- بنسبة أبعاد مناسبة للفيديو.
- سريعة التحميل.
- Lazy Loading.
- تحميل المعاينات أثناء التمرير.
- عدم تحميل جميع الفيديوهات دفعة واحدة.
- عدم تجميد الواجهة أثناء إنشاء المعاينات.

==================================================
4. اختيار Frame المعاينة
==================================================

لا تستخدم أول Frame دائمًا.

يفضل استخراج Frame من نسبة زمنية مناسبة من الفيديو، مثل:

10% من مدة الفيديو

أو:

اختيار Frame من عدة نقاط ثم اختيار أفضل Frame.

ويجب توفير إعداد للمستخدم:

- أول Frame.
- 5%.
- 10%.
- 25%.
- منتصف الفيديو.
- اختيار تلقائي.

ويجب أن يكون الاختيار التلقائي سريعًا.

27. أهم مبدأ تقني
==================================================

لا تعتمد على Android MediaStore وحده لاستخراج معاينات ملفات USB.

لأن وحدات USB/OTG قد لا تكون مفهرسة بالطريقة نفسها التي يتم بها فهرسة التخزين الداخلي.

يجب أن يستطيع التطبيق الوصول إلى الملف نفسه عبر URI/SAF ثم استخراج Thumbnail مباشرة من الفيديو.

استخدم Android APIs المناسبة مثل:

ContentResolver
DocumentFile
ParcelFileDescriptor
MediaMetadataRetriever
ContentResolver.loadThumbnail

مع بديل مناسب عند الحاجة.

يجب أن يكون التطبيق قادرًا على إنشاء Thumbnail حتى عندما لا تكون الفلاشة مفهرسة في MediaStore، طالما أن التطبيق يملك صلاحية قراءة الملف.

Android يوفر رسميًا آليات لاستخراج Thumbnails للفيديو، وContentResolver.loadThumbnail هو الأسلوب الحديث المفضل بدل API القديمة الخاصة بـ MediaStore.Video.Thumbnails.
